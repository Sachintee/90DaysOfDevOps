# Day 27 – GitHub Profile Makeover

## GitHub Profile Audit

### Profile Picture
Use a clear and professional profile picture.

### Bio
Write a short bio mentioning your role and learning journey.

Example:
MCA Student | DevOps Learner | 90 Days of DevOps | Linux • Git • AWS

### Pinned Repositories
Pin your best 6 repositories with proper README files.

### Repository Descriptions
Add a one-line description for every repository.
