# My 90-Day DevOps Learning Plan

## Current Level

I am an MCA student with basic knowledge of Python, Linux, Networking, and Cloud Computing.

## My Understanding of DevOps & Cloud

DevOps combines development and operations to automate software delivery and improve reliability. Cloud Engineering focuses on deploying and managing applications and infrastructure on cloud platforms.

## Why I Am Learning DevOps & Cloud

I want to build industry-ready skills, gain hands-on experience with modern tools, and prepare for DevOps and Cloud Engineer roles.

## My Goals for the Next 90 Days

1. Build and deploy applications using Docker and Kubernetes.
2. Create CI/CD pipelines using Jenkins and GitHub Actions.
3. Deploy cloud infrastructure on AWS using Terraform.

## Core Skills to Build

1. Linux Administration & Troubleshooting
2. CI/CD Automation
3. Docker, Kubernetes & AWS

## Weekly Time Budget

* Weekdays: 2–3 hours/day
* Weekends: 5–6 hours/day
* Total: 22–25 hours/week

## How I Will Stay Consistent

* Study and practice daily.
* Make at least one GitHub commit every day.
* Focus on hands-on projects and labs.
* Review progress every weekend.

This 90-day plan is my roadmap to become job-ready for DevOps and Cloud Engineering roles.
